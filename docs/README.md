# Documentazione del Traduttore

Il Traduttore è un'applicazione web statica che traduce documenti mantenendo il formato di ingresso o convertendolo in un altro. Tutta l'elaborazione avviene nel browser; il testo da tradurre viene inviato all'API di Anthropic con la chiave dell'utente.
